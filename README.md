# Project Title (Update)

A calculator which generates the N-th number in the fibonacci sequence

## Instructions for Build and Use

Steps to build and/or run the software:

1. Open ERL shell
2. run "c(fibonacci)." which will compile the file "fibonacci"
3. one compilied run "fibonacci:calc(N)." where N is the digit in the sequence you want to know.

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* Download erlang
* Run it in VIM or other text editor. Had issues with VSCode
